Market Cycle Trader API v1.13.43 validation
============================================

Scope
-----
Strategy-owned model binding for Backtest execution.

Validated behavior
------------------
- Every editable Strategy stores an immutable research model snapshot containing model family and validated model settings.
- Cloning a Strategy copies its saved model snapshot; changing the clone's model does not mutate the source Strategy or Trader Winner.
- Saving model parameters uses a separate model-binding revision and does not silently change the shared Strategy parameter revision.
- Editing shared Strategy parameters preserves the selected model but invalidates the previous Backtest certification for the new Strategy revision.
- POST /api/jobs resolves the model only from the selected Strategy; no Backtest request or UI override is accepted by the normal execution path.
- The legacy Administrator model-research job route cannot override a different model; it delegates only when the requested family matches the selected Strategy model.
- If a completed historical job has the same Strategy revision, model family and exact validated parameter values, saving that model adopts the immutable job snapshot and preserves eligibility without rerunning.
- Candidate certification requires the saved Strategy model and an exact completed model configuration.
- Winner promotion freezes the certified job model snapshot and continues supporting XGBoost and LightGBM live engines.
- IQN remains Research-only.
- Legacy XGBoost jobs without explicit model settings are reconstructed from the Strategy-owned XGBoost values for backward compatibility.
