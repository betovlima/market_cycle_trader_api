## Candidate root cause, not yet proven on the user's actual snapshot
Writer `_bars_payload` uses `%.17g` precision sufficient for binary64
roundtrip. Validation used pandas default float parser (the "high" parser),
which is not contractually an exact binary64 round-trip parser.
The source manifesto already records each asset's
`per_asset.<symbol>.normalized_history_sha256` from the original
**in-memory** normalized OHLCV, independently of CSV file hashes.
Thus v10.8.40 could accept identical file bytes while loading changed
numeric feature inputs. LightGBM tree splits may be sensitive even to
very small input representation differences; source-specific causality
needs a real rerun and the integrity report.

## Implementation
1. Reopen normalized CSV with `float_precision="round_trip"`.
2. Before any model training, compare each loaded asset's
   `_history_frame_sha256` against original in-memory
   `normalized_history_sha256` from the immutable manifest; require
   all eligible assets (55 for current snapshot) to match exactly.
   Fail closed if a hash is absent or mismatched. Keep the 56-asset
   universe, DOC structural exclusion, complete file SHA checks and
   completed XNYS date checks unchanged. Never repair, rewrite or
   regenerate source data as a workaround.
3. Publish `numeric_input_integrity` in report showing
   `verified`, `round_trip`, number of assets and hash method.
4. Keep separate report directory:
   `dados/control_shadow/snapshots/<source_id>/validation/v10.8.41/<validation_id>`.
   Preserve the v10.8.40 reports for causal comparison.
5. Add regression tests for independent in-memory model input mismatch,
   for adversarial float64 values and exact binary identity, and for
   all existing no-download/no-orders routes.

**Important:** The purpose is to establish equality of input numeric
matrices to original source OHLCV; a successful hash alone does not
guarantee identical trained LightGBM model/output. The new run must
also compare `original_shadow.reproduced`. If it remains false while
input hash verification passes, investigate deterministic LightGBM
environment and per-symbol model fingerprints, not change policy
parameters to force agreement.
