## Regra de dados operacionais

O checkpoint de US$ 58,56M é uma referência histórica, não um target para
otimização.

No MCT operacional:

1. baixar RAW diário da Alpaca SIP;
2. baixar Corporate Actions;
3. aplicar normalização causal de splits;
4. excluir identidade estrutural quebrada;
5. nunca fazer bridge manual de série;
6. registrar snapshot/hashes;
7. executar o engine científico sobre os ativos elegíveis.

Isso significa que o capital operacional pode divergir do checkpoint mesmo
com a política correta.

Importante: o replay científico U67 congelado manteve explicitamente CLMT para
reproduzir o checkpoint histórico. O MCT operacional não deve usar esse
override: se CLMT continuar caracterizado como identidade estrutural quebrada,
ele será excluído e a exclusão será registrada.
