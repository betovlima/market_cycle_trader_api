# MCT API v10.8.51 — Reduced Signature Meta-Veto Research

## Objetivo

Medir, sem alterar a política operacional, se a assinatura reduzida confirmada
na v10.8.50 melhora o capital quando usada somente como veto conservador de uma
rotação ativo->ativo já proposta pelo Control.

## Modelo congelado

Logistic Regression balanceada, L2, C=0.25.

Exatamente as nove features da v10.8.50:

## Protocolo temporal

- Fold 1: meta-modelo sempre desabilitado.
- Fold 2: somente labels do Fold 1.
- Fold 3: somente labels dos Folds 1+2.
- Em cada histórico anterior: split cronológico 70/30 treino/calibração.
- Depois de passar o gate, refit em todo o histórico anterior.
- Labels de treino continuam sempre vindo do dataset baseline da v10.8.49.
- Features de decisão durante o replay usam o estado real da trajetória meta.

## Gate fail-safe congelado

O modelo de um fold só é habilitado quando:

- calibração >= 20 eventos;
- Balanced Accuracy >= 0.52;
- ROC AUC >= 0.52.

Se qualquer condição falhar, o fold executa Control puro.

## Regra de veto congelada

Somente quando:

- modelo do fold está habilitado;
- incumbent != CASH;
- candidate != CASH;
- candidate != incumbent;
- P(ROTATE melhor) <= 0.35.

Ação: HOLD do incumbent por uma decisão.

Nunca altera CASH->ativo, ativo->CASH ou HOLD.

## Paridade obrigatória

`US$ 1.078.635,4115518222`

da v10.8.44 Liquidity-Aware, com tolerância absoluta 1e-6.
