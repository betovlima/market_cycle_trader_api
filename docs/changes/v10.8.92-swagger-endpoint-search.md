# API v10.8.92 — Busca rápida no Swagger (/docs)

## Pedido

Encontrar com facilidade os endpoints existentes em uma API com muitos grupos,
sem precisar percorrer manualmente toda a documentação interativa.

## Implementação

Foi habilitada a opção nativa do Swagger UI na construção do FastAPI:

```python
swagger_ui_parameters={
    "filter": True,
    "docExpansion": "none",
    "tagsSorter": "alpha",
    "operationsSorter": "alpha",
    "deepLinking": True,
}
```

Em `/docs`, o campo de filtro do Swagger aparece na parte superior da lista
de operações. Digitando parte do nome da **tag**, o Swagger mostra apenas os
grupos correspondentes. Exemplos:

- `tcc-u77-fixed-challenger` — cadastro e execução do U67+10
- `jobs` — jobs de backtest
- `strategy` — grupos com tag que contenha esse termo

As seções abrem recolhidas por padrão e são ordenadas alfabeticamente.
Os endpoints dentro de cada grupo também são ordenados alfabeticamente.
`deepLinking` permite criar URLs para operações selecionadas.

### Limitação da busca nativa

O filtro padrão do Swagger UI **procura correspondência nas tags**, e não é
um mecanismo de pesquisa em texto completo por qualquer fragmento do
caminho HTTP, request body ou descrição. Para encontrar um caminho exato,
filtre primeiro pela tag do módulo.

## Compatibilidade

A implementação altera apenas a apresentação da documentação interativa.
Nenhum endpoint, autenticação, execução de backtest, Strategy, Candidate ou
Winner foi criado, removido ou alterado.
