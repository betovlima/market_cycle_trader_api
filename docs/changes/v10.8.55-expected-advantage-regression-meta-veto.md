# MCT API v10.8.55 — Expected Advantage Regression Meta-Veto

## Objective

Increase final capital relative to the frozen v10.8.53 reference by predicting
the economic rollout advantage directly instead of classifying only ROTATE/HOLD.

The candidate target is:

`delta_capital_fraction = (ROTATE ending equity - HOLD ending equity) / initial equity`

## Frozen reference

The same job must reproduce before candidate evaluation:

- v10.8.44 Liquidity-Aware: `US$ 1,078,635.4115518222`
- v10.8.53 One-shot Meta-Veto: `US$ 1,891,417.6670329159`

Absolute tolerance: `1e-6`.

## Candidate

Fixed model:

- Ridge Regression;
- alpha = 1.0;
- SimpleImputer(median);
- StandardScaler;
- same 9 v10.8.53 features.

No alpha search.

## Calibration gate

Chronological 70/30 split on fully matured prior-rollout labels.

Candidate fold is enabled only when:

- calibration rows >= 20;
- sign Balanced Accuracy >= 0.52;
- Spearman(predicted delta, actual delta) > 0.0.

## Veto

No tuned probability threshold exists.

If:

`predicted_delta_capital_fraction <= 0.0`

then HOLD once.

The next policy call is forced to Control exactly as in v10.8.53.

CASH transitions remain untouched.

## Temporal protocol

- Fold 1: no model;
- Fold 2: fully matured Fold 1 labels only;
- Fold 3: fully matured Fold 1+2 labels only;
- `rollout_end_date < test_start`.
