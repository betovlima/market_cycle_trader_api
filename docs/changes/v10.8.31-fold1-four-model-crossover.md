## This version

`scripts/audit_tcc_v106_fold1_model_crossover.py` independently verifies
the same frozen TCC file hashes, completed paired-calibration output and
archived MCT RAW/normalized hashes. It trains ONLY the 55 Fold-1 calibration
models for each source, then obtains row-wise predictions using the exact
policy inference path.

For every switch-margin candidate, it evaluates each source dataset with
its own models, then swaps one of the four changed prediction columns at a
time, or all four together. Both exchange directions are tested:

- TCC price frames with MCT score columns;
- MCT price frames with TCC score columns.

Model fitting is **not repeated per swap** and no source snapshots or
production policy are altered. The replay first validates that row-wise
baseline candidate scores reproduce the prior paired audit to 1e-10 and
the Strategy #11 archived scores, otherwise it aborts. Also verifies that
the set of affected score columns reproduces the prior 504 mismatches.

Outputs: `report.json`, `crossover_candidate_scores.csv`,
`first_transition_differences.csv`, packaged as
`tcc_v106_fold1_four_model_crossover.zip`.

## How to interpret the crossover

If swapping all four columns changes TCC's chosen margin to 0.01 and MCT's
to 0.0, prediction shifts are sufficient to explain the margin change
under fixed prices. Single-column swaps then reveal whether one symbol is
sufficient or several interact. If not, subtle price-value changes or
additional model-score effects remain; do not claim causality without the
counterfactual score traces.

This is a Fold-1 calibration diagnostic only, not a portfolio profit forecast
or full historical v1.0.6 reproduction.
