# MCT API v10.8.47 — Control Counterfactual Advantage Meta-Veto

## Objetivo

A v10.8.47 abandona a ideia de substituir o ranking do Control. As v10.8.45
(TinyTCN regressão) e v10.8.46 (pairwise ranking) mostraram que a rede neural
não possui skill suficiente para escolher diretamente entre os 55 ativos.

O Control científico continua sendo a referência principal de modelagem:
**US$ 5.887.904,38**. O cenário executável v10.8.42 (**US$ 528.709,78**) é
uma simulação de exequibilidade, e a v10.8.44 Liquidity-Aware
(**US$ 1.078.635,41**) continua sendo o melhor caminho histórico com as
restrições de execução usadas nesta linha de pesquisa.

## Nova hipótese

O Control/Liquidity-Aware continua propondo a ação. O novo modelo recebe
somente o par:

`incumbent atual -> candidato proposto pelo Control`

e estima se a rotação possui vantagem sobre manter o incumbent.

A v10.8.47 não rankeia o universo, não escolhe um segundo candidato e não
inventa uma nova escala absoluta de utility.

## Target contrafactual da primeira implementação

Para evitar um target absoluto, usamos um target emparelhado na mesma data:

`advantage = weighted_forward_return(candidate) - weighted_forward_return(incumbent)`

com os mesmos horizontes 5/10/20/40/60 e pesos 0.10/0.15/0.20/0.30/0.25.

Esse target é **vantagem local de ação**, não uma alegação de DeltaCapital
exato da carteira completa. Um rollout de capital estado-dependente é uma
extensão posterior e não deve ser confundido com este rótulo.

Todos os 60 pregões precisam maturar antes da fronteira de
calibração/teste. Features são somente as 12 features causais já congeladas,
em janela de 40 sessões, usando a diferença candidato menos incumbent.

## Regra fail-safe

O modelo só pode interferir em rotação ativo -> ativo.

- entrada CASH -> ativo: Control;
- saída ativo -> CASH: Control;
- HOLD: Control;
- modelo sem score: Control;
- skill de calibração insuficiente: Control;
- probabilidade de vantagem > 0,40: Control;
- probabilidade de vantagem <= 0,40 e modelo habilitado: veto, mantém incumbent.

A ativação exige pelo menos 30 amostras de calibração e balanced accuracy
>= 0,55. Esses valores são fixos antes do novo OOS e não entram como
parâmetro HTTP.
