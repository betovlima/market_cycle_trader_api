# API v10.8.24 — Switch-margin calibration audit

## Context

The TCC is the frozen scientific reference and must not be modified for this
investigation.

The current MCT Strategy #11 uses the same configured switch-margin contract
observed in the frozen TCC reference:

- base switch margin: `0.0005`
- calibration candidates: `0.0, 0.0025, 0.005, 0.01`

The first material divergence already identified between both projects occurs in
walk-forward fold 1. At that point the model utility scores can match while the
calibrated switch margin differs.

This release investigates that divergence exclusively inside MCT.

## Added audit

For each switch-margin candidate in every fold, MCT now performs a second,
read-only replay after the official score is computed.

The audit replay records one row per calibration transition with:

- fold;
- candidate margin;
- decision date and next date;
- source and destination positions/assets;
- holding days before the decision;
- policy score;
- transition log return;
- risk-adjusted reward;
- cumulative risk-adjusted score;
- wealth before/after;
- peak before/after;
- whether the position changed.

The replay returns its own total score only for validation. The official
candidate-selection score remains the pre-existing score.

Each candidate summary now also includes:

- `risk_adjusted_score` — official selection score;
- `audit_trace_score` — total reconstructed from the diagnostic replay;
- `audit_score_delta` — diagnostic difference between both calculations.

A non-zero delta would itself identify an unexpected stateful or non-repeatable
calibration behavior.

## Export

The normal backtest ZIP now includes two additional files for each portfolio
run:

- `*_switch_margin_calibration_candidates.csv`
- `*_switch_margin_calibration_trace.csv`

The first file is a compact fold/candidate table.

The second file contains the session-by-session construction of the calibration
score and is intended to locate the exact date on which margin `0.01` gains or
loses relative to margin `0.00`.

## Investigation target

For Strategy #11 fold 1, the current MCT execution previously reported:

- margin `0.0000`: approximately `-1.6259029200`
- margin `0.0025`: approximately `-1.6259029200`
- margin `0.0050`: approximately `-1.6259029200`
- margin `0.0100`: approximately `-1.6191540889`

Therefore `0.01` was selected.

The next execution should identify the exact calibration transition(s)
responsible for the score difference between `0.00` and `0.01`.
