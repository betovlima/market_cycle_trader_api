## Correção local de importação no Spyder / Python 3.14 (28/09/2026)
- Sintoma: `ModuleNotFoundError: No module named 'market_cycle_trader_api'` durante o carregamento de `test_tcc_control_operational_parity.py`. Isso ocorre antes de executar qualquer asserção da política.
- Causa: o interpretador local não inclui `<raiz da API>/src` em `sys.path`, apesar de a CI configurar `PYTHONPATH=src`.
- Correção versionada: somente o teste novo inclui o diretório `src` a partir do seu próprio `__file__` antes dos imports da API, sem depender do diretório corrente do Spyder. O código operacional não foi alterado.
- A execução CI anterior no commit `66e31f6f0be882b5bb3980776d8240c0e29a30ab` concluiu com sucesso em Python 3.12. A nova correção exige sua própria confirmação de CI.
- Python de referência do repositório é 3.12. O erro isolado não demonstra compatibilidade nem incompatibilidade com Python 3.14.2; dependências nativas precisam ser instaladas no mesmo interpretador do Spyder.
- Uso local recomendado: executar `%run tests/test_tcc_control_operational_parity.py` no console IPython do Spyder a partir da raiz da API, ou executar a descoberta do `unittest` como no comando PowerShell abaixo.
